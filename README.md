# Valorant Tracker

App de escritorio en Python (CustomTkinter) para consultar rango, estadísticas e historial de partidas de jugadores de Valorant usando su Nombre#TAG.

Los datos se obtienen a través de la API de HenrikDev mediante un proxy intermedio en Vercel.

## Aviso

Proyecto no oficial. No está asociado ni respaldado por Riot Games. Valorant y Riot Games son marcas registradas de Riot Games, Inc.
